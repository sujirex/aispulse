AISPulse User Guide

AISPulse is a real-time vessel tracking dashboard for Indian coastal waters. It decodes AIS radio messages and displays vessel positions, trajectories, port alerts, and analytics on a live map.

Overview

Live AIS Feed
Connects to any NMEA over TCP data source — or runs the built-in simulator with 20 Indian coastal vessels.
Interactive Map
Leaflet.js map with CartoDB tiles. Vessels shown as heading-rotated triangles coloured by type.
Port Alerts
Detects when vessels enter or leave any of 12 monitored Indian port zones in real time.
Analytics
Speed history chart, fleet statistics, and live NMEA feed log — all in one view.

Interface

The dashboard is divided into four zones:

Navbar (top)
Shows fleet statistics (total, underway, anchored, moored), data source badge, map centre button, and dark/light theme toggle.
◀
Sidebar (left)
Lists all tracked vessels with real-time speed. Includes a text search bar and vessel type filter chips.
Map (centre)
Interactive Leaflet map. Port zone circles, vessel markers, and selected vessel track are overlaid here.
NMEA Log (bottom)
Scrolling feed of raw AIS sentences as they arrive, with timestamp and MMSI. Keeps the last 80 entries.
Detail Panel (floats over map)
Opens when you click a vessel. Shows full static data, speed chart, and export buttons.

Map Controls

Zoom
Use + / − buttons (top-left of map), scroll wheel, or pinch on touch screens.
Pan
Click and drag anywhere on the map.
Re-centre
Click the crosshair button in the navbar to snap back to Indian coastal waters (14°N, 78°E, zoom 5).
Select Vessel
Click any vessel marker to pan the map and open the Detail Panel.
Port Zone Circles
Dashed teal circles show the 12 monitored port zones. Hover to see the port name.

Sidebar & Filters

Search

Type in the search bar to filter by vessel name, MMSI number, or ship type. The filter applies to both the list and the map markers.

Type Filter Chips

Click a chip to show only vessels of that type. The All chip clears the filter. Active filter is highlighted in teal.

Tip: Type filter and text search combine — you can filter to Tankers and then search by MMSI.

Vessel Detail Panel

Click any vessel (on the map or in the sidebar list) to open its detail panel.

Static Data
MMSI, Call Sign, IMO, Ship Type, Navigation Status, Destination.
Dynamic Data
Speed (SOG), Course (COG), Heading, Latitude/Longitude, Last Seen timestamp.
Speed History Chart
SVG sparkline of the last 40 SOG readings. Updates live while the panel is open.
Track Overlay
The vessel's breadcrumb track (up to 120 points) is drawn as a dashed polyline on the map.
To close the panel, click the ✕ in the top-right corner. The track overlay is removed automatically.

Port Alerts

AISPulse monitors 12 major Indian port zones. When a vessel enters or departs a zone, a toast notification appears in the bottom-right corner.

Green toast — Entered
Vessel has moved inside the port boundary circle.
Yellow toast — Departed
Vessel has moved outside the port boundary circle.

Toasts auto-dismiss after 6 seconds. Click a toast to dismiss it early.

Speed History Chart

The SOG (Speed Over Ground) sparkline inside the Detail Panel shows up to the last 40 position updates for the selected vessel. The chart updates automatically while the panel is open.

The top-right value is the current speed in knots. The top-left value is the chart's maximum (Y-axis top). The zero line is at the bottom.

The chart shows all received updates, not time-interpolated. Gap between updates depends on vessel transmit rate — typically every 2–10 seconds when underway.

Export Track

The Detail Panel has two export buttons at the bottom. Both download the selected vessel's breadcrumb track.

CSV — track_MMSI.csv
Three columns: timestamp (ISO 8601), latitude, longitude. Open in Excel or import into GIS tools.
KML — track_MMSI.kml
Google Earth / Maps format. Opens directly in Google Earth Desktop, My Maps, or any KML-compatible GIS application.
Note: The server stores up to 120 track points per vessel. Export shortly after a long voyage for the best coverage.

NMEA Log

The bottom strip shows raw AIS sentences in real time. Each row contains:

12:34:56   123456789   !AIVDM,1,1,,B,15M2TR0P00GQ3f`E…,0*5B

Columns: Time · MMSI · Raw NMEA sentence. Up to 80 entries are kept. This is useful for debugging a live TCP feed or verifying that sentences are being decoded correctly.

Running AISPulse Locally

Install Go 1.21+ from go.dev/dl.
Open a terminal in the aispulse/ directory.
Fetch dependencies:

go mod tidy
Simulator mode (default):
go run . -sim

Live TCP feed mode:
go run . -feed 153.44.253.27:5631

Both at once:
go run . -sim -feed 153.44.253.27:5631
Open http://localhost:8080 in your browser.

Command-line Flags

FlagDefaultPurpose
-addr:8080HTTP server listen address
-simtrueEnable built-in vessel simulator
-feedemptyLive AIS TCP feed host:port

Build as a Single Binary

go build -o aispulse.exe .
.\aispulse.exe -addr :8080

The binary embeds the entire web frontend — no separate web server or file serving needed.

Live Data Sources

AISPulse connects to any NMEA-over-TCP AIS data provider. Here are the main sources of real AIS data you can plug in:

AISHub aishub.net
Free community-shared AIS network. Register for an account and you get access to a global raw NMEA TCP feed. Typical address format: data.aishub.net:5631. Non-commercial use only.
MarineTraffic / VesselFinder
Commercial-grade live AIS APIs via REST/WebSocket. Require API subscription. Better for production; not NMEA TCP format — would need an adapter layer.
Own VHF AIS Receiver (RTL-SDR / dedicated decoder)
Connect a software-defined radio (e.g. RTL-SDR dongle) with AIS decoder software like AIS-catcher or AIS Dispatcher. These output NMEA sentences over a local TCP port — perfect for AISPulse. Coverage is limited to your VHF range (~20–40 NM).
🇮🇳
Indian Coast Guard / VTMS feeds
Vessel Traffic Management System (VTMS) feeds at major Indian ports (Mumbai, Chennai, Kochi, Visakhapatnam) provide AIS data to authorised receivers. Contact the respective Port Trust / DGLL for access.

Connecting a Feed

Register with AISHub and get your server address + port.
Run AISPulse with the -feed flag:

go run . -feed data.aishub.net:5631
The source badge in the navbar will switch from SIM to ● LIVE once the WebSocket connects. Real vessels appear on the map within seconds.
You can run the simulator alongside the live feed for testing: go run . -sim -feed data.aishub.net:5631
Built-in simulator: When no live feed is available, AISPulse starts 20 simulated Indian coastal vessels by default. Toggle with -sim=false to disable.

AIS Primer

AIS (Automatic Identification System) is an internationally mandated VHF radio system. All vessels over 300 GT, all cargo ships over 500 GT, and all passenger ships broadcast AIS on channels 87B (161.975 MHz) and 88B (162.025 MHz).

What AIS Broadcasts

Message TypeContentsRate
Type 1/2/3Position, SOG, COG, Heading, Nav StatusEvery 2–10 sec (underway)
Type 5Ship name, Call sign, IMO, Destination, DimensionsEvery 6 min
Type 18Class B position report (smaller vessels)Every 30 sec
Type 24A/BClass B static data (name, type)Every 6 min

AIS Terms Glossary

TermMeaning
MMSIMaritime Mobile Service Identity — 9-digit unique vessel ID
SOGSpeed Over Ground — GPS-derived speed in knots
COGCourse Over Ground — GPS-derived direction of travel (0–359°)
HDGHeading — the direction the bow is pointing (may differ from COG in current/wind)
IMOInternational Maritime Organization vessel number (permanent)
NMEANational Marine Electronics Association — sentence format (e.g. !AIVDM,...,*XX)
Nav StatusSelf-reported operational state: Underway, Anchored, Moored, Not under command, etc.
GTGross Tonnage — measure of vessel internal volume

How AISPulse Decodes Sentences

Each !AIVDM sentence contains a 6-bit ASCII encoded payload. AISPulse decodes the payload bit-by-bit: the first 6 bits identify the message type, followed by fixed-width fields for MMSI, nav status, speed, longitude, latitude, course, and heading.

!AIVDM,1,1,,B,15M2TR0P00GQ3f`E`JE`4?vN0<0e,0*5B
         ───── ─ payload (ASCII encoded 6-bit data) ─────

Character values are mapped from ASCII: char − 48, then & 0x3F. Fields are packed MSB-first with no byte alignment.
